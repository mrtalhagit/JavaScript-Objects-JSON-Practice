# 📦 JavaScript Practice — Objects & JSON

**Practical Coding Exercises | Beginner Level | JavaScript**

A collection of JavaScript practice exercises focused on objects, arrays of objects, functions, array methods, and data manipulation.

---

## 🎯 Project Overview

This repository documents my practice with **JavaScript Objects and JSON Fundamentals**.

The goal of this practice session was to understand how objects store and organize data, how to access and manipulate object properties, and how to work with arrays containing multiple objects.

I practiced solving 10 programming challenges using different JavaScript functions and array methods to perform operations such as searching, filtering, grouping, calculating, and updating product information.

## 📚 Concepts Explored

| Concept | Description |
|---|---|
| Objects | Storing data using key-value pairs |
| Arrays of Objects | Managing multiple objects in an array |
| `find()` | Finding a specific object |
| `filter()` | Selecting objects based on conditions |
| `map()` | Transforming array elements |
| `reduce()` | Calculating and combining array values |
| `forEach()` | Iterating through array elements |
| Spread Operator (`...`) | Copying and updating objects |
| Object Properties | Accessing and modifying object values |
| Arrow Functions | Writing shorter function expressions |
| Conditional Statements | Applying conditions to object data |
| Functions | Creating reusable operations |

## 💻 Challenges Completed

I completed 10 programming challenges based on a product inventory system.

| # | Challenge | Description |

| 04 | Get Top Rated Product | Find the product with the highest rating |
| 05 | Group by Category | Group product titles according to their categories |
| 06 | Average Product Price | Calculate the average price of all products |
| 07 | Get Titles by Category | Filter products and return titles from a specific category |

Replace `q1.js` with the exercise you want to execute.
